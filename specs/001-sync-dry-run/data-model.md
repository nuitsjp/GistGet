# データモデル: sync dry-run

## 同期元パッケージ

既存の `GistGetPackage` に対応する。同期元に記録された期待状態を表す。

### フィールド

- `Id`: パッケージ識別子。比較キー。必須。
- `Name`: 表示名。表示用。
- `Version`: 期待バージョン。アップグレード予定の判定に使う。
- `Pin`: 期待するピンバージョン。ピン追加、更新、アップグレード予定の判定に使う。
- `PinType`: ピン種別。ピン追加または更新予定の表示に使う。
- `Uninstall`: アンインストール対象かどうか。

### 検証ルール

- `Id` は空であってはならない。
- `Uninstall` が true の場合、インストール予定、アップグレード予定、ピン追加または更新予定には分類しない。
- `Pin` が空の場合、ローカルにピンがあればピン削除予定として扱う。

## ローカルパッケージ状態

既存の `WinGetPackage` と `WinGetPin` から取得する端末の現在状態を表す。

### フィールド

- `Id`: パッケージ識別子。同期元パッケージとの比較キー。
- `Name`: 表示名。表示用。
- `Version`: 導入済みバージョン。期待バージョンまたは期待ピンとの差分判定に使う。
- `PinnedVersion`: 現在のピンバージョン。期待ピンとの差分判定に使う。

### 検証ルール

- 比較は `Id` を大文字小文字を区別せずに行う。
- ローカルに存在しない通常パッケージはインストール予定に分類する。
- ローカルに存在する削除対象パッケージはアンインストール予定に分類する。

## プレビュー結果

dry-run でユーザーへ表示する分類結果。`SyncResult` を拡張して保持する。

### フィールド

- `Installed`: インストール予定の同期元パッケージ一覧。
- `Uninstalled`: アンインストール予定の同期元パッケージ一覧。
- `Upgraded`: アップグレード予定の同期元パッケージ一覧。
- `PinUpdated`: ピン追加または更新予定の同期元パッケージ一覧。
- `PinRemoved`: ピン削除予定の同期元パッケージ一覧。
- `UnchangedCount`: 更新不要として分類された件数。
- `Failed`: 読み込みや分類で処理できなかった対象と理由を既存形式で表す。
- `IsDryRun`: dry-run の結果かどうか。

### 分類ルール

1. 同期元で `Uninstall` が true かつローカルに存在する場合、アンインストール予定に分類する。
2. 同期元で `Uninstall` が false かつローカルに存在しない場合、インストール予定に分類する。
3. 同期元で期待バージョンまたは期待ピンがあり、ローカルバージョンと異なる場合、アップグレード予定に分類する。
4. 同期元に期待ピンがあり、ローカルのピン状態と異なる場合、ピン追加または更新予定に分類する。
5. 同期元に期待ピンがなく、ローカルにピンがある場合、ピン削除予定に分類する。
6. どの予定にも分類されない同期元パッケージは更新不要として数える。

### 状態遷移

```text
同期元読み込み
  -> ローカル状態取得
  -> 差分分類
  -> プレビュー結果表示
  -> 外部状態変更なしで終了
```
