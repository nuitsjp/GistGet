# CLI 契約: sync --dry-run

## コマンド

```text
gistget sync [--url <URL>] [--file <PATH>] [--dry-run]
```

## オプション

| オプション | 必須 | 説明 |
|------------|------|------|
| `--dry-run` | いいえ | 同期内容をプレビューし、実際の変更を行わない。値は受け取らない。 |
| `--url <URL>` | いいえ | 指定 URL の同期元を使う。 |
| `--file <PATH>` | いいえ | 指定ファイルの同期元を使う。 |

## 正常時の振る舞い

- `--dry-run` 指定時は、実行予定の操作種別と対象件数を表示する。
- 表示対象は、インストール予定、アンインストール予定、アップグレード予定、ピン追加または更新予定、ピン削除予定、更新不要件数とする。
- 差分が存在しても、プレビューが完了した場合の終了コードは `0` とする。
- `--url` または `--file` と同時に指定した場合、指定された同期元を使ってプレビューする。

## 禁止される副作用

`--dry-run` 指定時、次の操作は実行してはならない。

- パッケージのインストール
- パッケージのアンインストール
- パッケージのアップグレード
- ピン追加、ピン更新、ピン削除
- Gist への保存または更新

## エラー時の振る舞い

- 同期元の読み込みに失敗した場合は、通常の `sync` と同じエラーとして扱う。
- エラー時も、読み込み済みまたはローカルの外部状態を変更してはならない。

## 互換範囲

- `--dry-run` を指定しない `sync` の動作は変更しない。
- `--url` と `--file` の意味や指定方法は変更しない。
- 機械処理用の出力形式はこの契約に含めない。
